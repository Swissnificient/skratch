# Changelog

## 0.4.0

- Added redirect-safe public website fetching.
- Expanded non-public host rejection for IPv4 and IPv6 destinations.
- Added bounded retries for transient website failures.
- Added structured background diagnostics without persistent telemetry.
- Added fallback selector adapters for Google Maps result, website, and title elements.
- Added network security tests.
- Added Chrome Web Store release guidance.
- Added 16, 32, 48, and 128 pixel extension icons.

## 0.3.0

- Reworked enrichment as a persistent Manifest V3 job.
- Added stable lead IDs and non-destructive merges.
- Added cancellation, recovery watchdog, response-size limits, CSV protection, and baseline tests.
